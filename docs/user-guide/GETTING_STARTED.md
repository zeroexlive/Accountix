# Getting Started (Sprint 01 scope)

1. Start the app (see README quick start) and open `/login/`.
2. Log in with the superuser/staff account created by an administrator.
3. On the dashboard, create a company — you automatically become its owner.
4. Create a fiscal year for the company (dates must not overlap another
   fiscal year of the same company).
5. Build the chart of accounts: codes are unique per company; mark only
   leaf accounts as postable.

Journal entries, invoices and inventory are not available yet — they are
scheduled for the next sprints and this guide will grow with them.
